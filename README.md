# 腰痛

macOS 菜单栏健康提醒小工具。持续工作达到阈值后，菜单栏图标变红提醒你起身活动；离开工位休息一段时间后自动归零。

> 名字"腰痛"直白点出久坐对腰部的危害——比"久坐提醒"更扎眼。

## 功能

- 菜单栏图标常驻：白色 = 工作中，红色 = 超时。仅靠颜色变化，不弹窗不响铃。
- 双计时器：工作计时是墙钟（鼠标不动也累加），休息计时是空闲时长。休息达标后工作清零并挂"等待活动"门——必须**下一次输入**才重新开始。
- 系统休眠 / 唤醒时，自动视为已充分休息，唤醒后等用户输入才恢复计时。
- 启动后自动弹出主界面：双计时器 + 工作/休息时长调节 + 暂停开关 + 重启/退出。
- 配置持久化；暂停状态每次启动默认运行中。
- 活动检测走 `CGEventSource`，1 次/秒，无辅助功能权限，无全局事件监听器。

## 系统要求

macOS 12+ · Apple Silicon / Intel 通用

## 构建与运行

```bash
./build.sh release
open build/腰痛.app
```

## 测试

```bash
swift test                                            # 单元测试
build/腰痛.app/Contents/MacOS/Yaotong --smoke-test    # 端到端场景
```

## 配置

| 参数 | 默认 | 可选值 |
|------|------|--------|
| 工作时长 | 30 分钟 | 2 / 5 / 10 / 15 / 20 / 30 / 45 / 60 |
| 休息时长 | 10 分钟 | 1 / 2 / 5 / 10 / 15 / 20 / 30 / 45 / 60 |
