# 腰痛

macOS 菜单栏健康提醒小工具。持续工作达到阈值后，菜单栏图标变红提醒你起身活动；离开工位休息一段时间后自动归零。

> 名字"腰痛"直白点出久坐对腰部的危害——比"久坐提醒"更扎眼。

## 原理

**依靠检测鼠标/键盘的最近输入判断你是否在工作。** 每秒查一次 `CGEventSource`——不动用任何全局事件监听器，不需要辅助功能权限：

- 有活动（最近 1 秒有输入）→ **工作**，墙钟计时累加（即便你盯着屏幕不动鼠标，时间也走）
- 无活动 ≥ 休息阈值（默认 10 分钟）→ **充分休息**，重置工作计时，挂"等待活动"门，必须下一次输入才重新开始
- 工作计时 ≥ 阈值（默认 30 分钟）→ **超时**，菜单栏图标变红（变红瞬间会闪 3 下提醒）

## 功能

- 菜单栏图标常驻，靠颜色区分三种状态：
  - **白** = 工作中
  - **红** = 超时（变红时闪 3 下再稳定）
  - **蓝** = 休息判定已命中，正在"等待活动"门里（用户回到工位、下一次输入后变白）
- 启动自动弹主界面：双计时器 + 时长调节 + 暂停 / 重启 / 退出 / 检查更新
- 系统休眠 / 唤醒 → 自动视为休息
- 配置持久化（暂停状态每次启动默认运行中，不持久化）
- 检查更新：菜单 + 主界面入口，GitHub Releases API，启动后 5s 后台静默检查一次（无更新不打扰），手动点击立即检查并弹结果

## 系统要求

macOS 12+ · Apple Silicon / Intel 通用

## 构建与运行

```bash
./build.sh release
open build/腰痛.app
```

## 测试

```bash
swift test                                            # 单元测试
build/腰痛.app/Contents/MacOS/Yaotong --smoke-test    # 端到端场景
```

## 配置

| 参数 | 默认 | 可选值 |
|------|------|--------|
| 工作时长 | 30 分钟 | 2 / 5 / 10 / 15 / 20 / 30 / 45 / 60 |
| 休息时长 | 10 分钟 | 1 / 2 / 5 / 10 / 15 / 20 / 30 / 45 / 60 |
